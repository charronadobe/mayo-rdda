# cards-action

Custom **cards** block. Purpose: Action tiles with title, text and one chevron CTA link; text-only tiles sit two per row, tiles with an image span the full width with the image on the right or behind the text.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: One row per tile, two cells. Text-only: (empty) | H2 title, paragraph, CTA link. Image right: H2 title, paragraph, CTA link | Image. Image background: Image | H2 title, paragraph, CTA link.
