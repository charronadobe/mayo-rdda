# quote-pull

Custom **quote** block. Purpose: Large light serif pull quote with an attribution (name, title) and an optional round avatar and chevron story link..

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: Row 1: quotation paragraph. Row 2 (optional): one cell with an optional avatar image, the name paragraph, then a title paragraph and/or a link paragraph..
