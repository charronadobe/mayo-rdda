# cards-overlay

Custom **cards** block. Purpose: Grid of photo cards with the linked title and subtitle overlaid on a dark gradient at the bottom of the image; the whole card is clickable.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: Image | Linked H3 title, subtitle; then Image | Linked H3 title, subtitle.
