# carousel-story

Custom **carousel** block. Purpose: Full-width story slider: each slide is a wide rounded photo with a caption and a story link over a dark bottom gradient; dash pagination and prev/next arrows are generated below the slides. No autoplay..

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: One row per slide, two cells: Image | caption paragraph, link paragraph ('Read ... story')..

## Supported variations

No variations.
