# cards-location

Custom **cards** block. Purpose: Location cards: a landscape photo beside an H2 title, a subtitle and a list of chevron links..

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: One row per location, two cells: Image | H2 title, subtitle paragraph, bulleted list of links..

## Supported variations

- Default (horizontal): the photo beside the text, one card per row (e.g. /care-at-mayo-clinic/locations).
- `stacked`: the photo above the text, cards side by side (1 column mobile, 2 tablet, 3 desktop), as on /care-at-mayo-clinic/patient-visitor-guide. Applied automatically when the block has more than one card and each card has at most one link; it can also be authored as `Cards Location (stacked)`. Author `Cards Location (horizontal)` to keep the default look regardless.
