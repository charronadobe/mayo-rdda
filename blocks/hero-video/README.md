# hero-video

Custom **hero** block. Purpose: Top-of-page hero with a full-bleed looping background video (muted, with a play/pause control) and overlaid H1, text link and CTA button.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: Video link (.mp4) and optional poster image; then H1 heading, optional paragraph, text link, CTA button.
