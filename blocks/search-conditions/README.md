# search-conditions

Custom **search** block. Purpose: Labelled pill-shaped search input that submits to a search results page, with optional type-ahead suggestions from a JSON index.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: Label text, e.g. Search diseases & conditions; then Link to the search results page; then Optional: link to a JSON index for suggestions; then Optional: placeholder text.

No variations.
