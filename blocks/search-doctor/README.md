# search-doctor

Custom **search** block. Purpose: Doctor search band: free-text term plus a location dropdown that submits a GET request to the Mayo Clinic doctor results page.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: Background photo; then H2 heading; then Field label | placeholder; then Location label | default option text (all locations); then one row per location: shown text | query value; then link to the results page (form action); then optional Search Tips link.
